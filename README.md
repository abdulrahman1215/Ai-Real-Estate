# Real Estate Platform — Backend

A production-ready REST API backend for a real estate search and property management platform. Built with FastAPI and PostgreSQL, featuring JWT authentication, role-based access control, advanced property search, and Docker-based deployment.

---

## Features

- **JWT Authentication & RBAC** — Secure login with role-based access for buyers, sellers, and agents
- **Property Listings API** — Full CRUD for property listings with validation via Pydantic schemas
- **Search & Filter Endpoints** — Query properties by location, price range, type, and amenities with pagination
- **Async Database Layer** — PostgreSQL with SQLAlchemy (async) and asyncpg for high-performance queries
- **Modular Architecture** — Clean separation of routers, services, models, and schemas
- **Dockerized Deployment** — Fully containerized with Docker Compose for consistent environments

## Getting Started

### Prerequisites

- Python 3.11+
- PostgreSQL 15+
- Docker & Docker Compose (recommended)

### Run with Docker (Recommended)

```bash
# Clone the repo
git clone https://github.com/abdulrahman1215/Ai-Real-Estate.git
cd Ai-Real-Estate

# Copy environment file
cp .env.example .env

# Start the stack
docker compose up -d
```

API will be live at `http://localhost:8000`
Swagger docs at `http://localhost:8000/docs`

### Run Locally

```bash
# Create and activate virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# Install dependencies
pip install -r backend/requirements.txt

# Set environment variables
cp .env.example .env
# Edit .env with your PostgreSQL connection string

# Run database migrations
alembic upgrade head

# Start the server
cd backend
uvicorn app.main:app --reload
```

## API Endpoints

### Auth
```
POST   /api/auth/register       Register a new user
POST   /api/auth/login          Login and receive JWT token
POST   /api/auth/refresh        Refresh access token
```

### Properties
```
GET    /api/properties          List all properties (paginated)
POST   /api/properties          Create a new listing (seller/agent only)
GET    /api/properties/{id}     Get property details
PUT    /api/properties/{id}     Update a listing (owner only)
DELETE /api/properties/{id}     Delete a listing (owner only)
```

### Search & Filter
```
GET    /api/search?location=Bangalore&min_price=2000000&max_price=5000000&bedrooms=2
```

## Database Schema

```
properties

  area_sqft, property_type, owner_id (FK → users), created_at, updated_at

property_images

```

## Key Design Decisions

**Why FastAPI?**
Async-first framework with automatic OpenAPI docs generation and native Pydantic integration — ideal for building clean, well-documented REST APIs quickly.

**Why asyncpg over psycopg2?**
asyncpg is a pure-async PostgreSQL driver that handles concurrent requests without blocking — better throughput for I/O-heavy endpoints like search and listing queries.

**Why Docker Compose?**
Eliminates "works on my machine" issues. Anyone can clone the repo and run the full stack with one command — easier for team handoff and deployment.
